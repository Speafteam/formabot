# ФормаБот

Telegram-бот для поддержания формы: две тренировки в день, счётчик БЖУ,
напоминания про еду и воду, отслеживание веса и заявки на живого тренера.

## Что нужно перед запуском

### 1. Токен бота — обязательно

1. Откройте в Telegram [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`, придумайте имя и адрес (адрес должен кончаться на `bot`)
3. BotFather пришлёт строку вида `1234567890:AAF...` — это токен

### 2. Ваш Telegram ID — обязательно

Напишите [@userinfobot](https://t.me/userinfobot), он ответит числом.
На этот ID бот будет слать заявки на работу с тренером.

### 3. Ключи FatSecret — можно позже

Счётчик еды берёт БЖУ из FatSecret. Без ключей работает всё остальное,
а на попытку записать еду бот честно скажет, чего не хватает.

1. Зарегистрируйтесь на [platform.fatsecret.com](https://platform.fatsecret.com)
2. Создайте приложение, скопируйте Client ID и Client Secret
3. **Внесите свой IP в белый список** в кабинете — на бесплатном тарифе
   без этого API отвечает отказом. Узнать IP: [ifconfig.me](https://ifconfig.me).
   Домашний IP обычно динамический, так что после смены его придётся обновлять.

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```bash
copy .env.example .env
```

```
BOT_TOKEN=1234567890:AAF...
ADMIN_ID=123456789
TZ=Europe/Moscow
FATSECRET_CLIENT_ID=
FATSECRET_CLIENT_SECRET=
```

Файл `.env` в git не попадает — токены остаются на вашей машине.

## Запуск

```bash
.venv\Scripts\python.exe -m bot.main
```

Бот напишет в консоль ссылку вида `https://t.me/ваш_бот` — открывайте и
жмите «Старт». Остановить — `Ctrl+C`.

Проверить логику без Telegram (токен не нужен):

```bash
.venv\Scripts\python.exe selfcheck.py
```

## Как устроено

| Файл | За что отвечает |
|---|---|
| `bot/main.py` | Запуск, сборка зависимостей |
| `bot/config.py` | Настройки, тарифы, время напоминаний по умолчанию |
| `bot/calc.py` | Норма калорий, БЖУ, вода, безопасный темп |
| `bot/db.py` | SQLite: пользователи, еда, вода, вес, таймеры, заявки |
| `bot/programs.py` | Сборка программ тренировок и ссылки на технику |
| `bot/fatsecret.py` | Поиск продуктов и расчёт БЖУ на граммовку |
| `bot/scheduler.py` | Напоминания и таймеры отдыха |
| `bot/parsing.py` | Разбор «гречка 150 г», веса, времени |
| `bot/handlers/` | Диалоги: регистрация, тренировка, еда, прочее |

### Расчёт нормы

Базовый обмен по Миффлину–Сан Жеору, умножается на коэффициент образа жизни
(1,375 / 1,55 / 1,725) плюс 0,15 за две тренировки в день. Дальше поправка на
цель: похудение −20 %, набор +15 %, растяжка и поддержание без изменений.

Белок 1,6–2,2 г на кг веса (на дефиците больше — он защищает мышцы),
жиры 0,9 г на кг, углеводы добирают остаток. Вода — 30 мл на кг плюс
500 мл за тренировочный день.

Норма пересчитывается при каждом взвешивании.

### Таймер отдыха

Мини-аппка не используется, живых часов в чате нет — обычный бот их не умеет.
Отсчёт идёт на сервере: после «Готово» ставится задача на 120 секунд, приходит
два сообщения — за 30 секунд до конца и по истечении. Оба новые, потому что
редактирование старого сообщения не даёт уведомления на телефон.

Таймеры пишутся в SQLite. Если бот перезапустится посреди тренировки, при
старте он поднимет незакрытые таймеры; просроченные срабатывают сразу.

### Программы

Собираются под цель, место (дом / зал / улица) и тип (силовая / кардио).
Утренняя выходит на 105–115 минут, вечерний блок — около 25.
В зале программа чередуется через день: низ тела и верх тела.

Ссылки на технику ведут в поиск YouTube, чтобы не протухали. Когда отберёте
свои ролики, замените `video` у нужного упражнения в `bot/programs.py`.

## Запуск на сервере

Пошаговая инструкция для VPS — в [DEPLOY.md](DEPLOY.md): systemd, перенос базы,
белый список IP для FatSecret, резервные копии.

Главное правило: **один запущенный экземпляр**. Если бот работает и на сервере,
и на компьютере, Telegram отдаёт обновления только одному, второй получает
`409 Conflict`, и сообщения начинают теряться.

## Что стоит доделать перед реальными пользователями

- Бот не врач. Перед запуском на людей добавьте дисклеймер и вопрос
  о травмах и противопоказаниях.
- Long polling подходит для одного сервера. Webhook понадобится, только если
  захотите держать несколько экземпляров за балансировщиком.
- Заявки на тренера складываются в таблицу `leads` и уходят админу
  сообщением. Обработки статусов («взял в работу», «отказ») пока нет.
- Аватарка бота ставится только через @BotFather, из кода это недоступно.
